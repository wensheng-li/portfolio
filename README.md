# Personal Portfolio — Setup & GitHub Pages Guide

A minimalist portfolio website focused on enterprise software engineering, backend systems, and business application development.

Designed with a dark editorial aesthetic and built using vanilla HTML, CSS, and JavaScript.

---


Open the project folder:

```bash

```

Run locally using VS Code Live Server or any local web server.

Example:

```bash

```

---

# 🌐 Deploying to GitHub Pages

## 1. Push project to GitHub

Create a new repository and upload the project files.

---

## 2. Enable GitHub Pages

Go to:

```plaintext
Repository → Settings → Pages
```

Under:

```plaintext
Build and deployment
```

Select:

```plaintext
Source → Deploy from a branch
```

Then choose:

```plaintext
Branch → main
Folder → /root
```

Save the settings.

---

## 3. Access your portfolio

Your site will be available at:

```plaintext
https://wensheng-li.github.io/portfolio/
```
